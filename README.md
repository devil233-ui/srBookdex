# srBookdex（星穹铁道文本图鉴）

米游社崩坏：星穹铁道 wiki 的文本检索与阅读插件，配合 [bookdex-plugin](https://github.com/KexinyingLife/bookdex-plugin)（原神）使用。

- 命令前缀：`*` 或 `＊`（全角半角都行），不带 `#`，避免和 bookdex 抢消息。
- 数据来源：`https://www.miyoushe.com/sr/wiki/`（`app_sn=sr_wiki`），只有文字与图标，不含攻略图。
- 数据目录 `data/` 由插件自己拉取生成，不进 Git 仓库。

## 首次使用

```text
*统一更新
```

第一次会把所有已启用分类拉一遍（约 3400 条详情请求，视网络可能需要 20~40 分钟）；也可以按分类单独拉，例如 `*阅读物更新`。

## 命令一览

更新（增量，只拉新增或有变化的条目）：

```text
*<分类>更新            例如 *阅读物更新
*统一更新              所有已启用分类
```

强制核对（逐条重新拉详情并与本地比对，能发现列表签名不变但正文变化的情况；条目多时较慢）：

```text
*<分类>强制更新        例如 *光锥强制更新
```

阅读与搜索：

```text
*<分类>帮助[页码]      列目录，再发 *<序号> 看内容
*<分类>搜索 <关键词>    在该分类里搜（走米游社搜索接口）
*搜索 <关键词>          在本地已下载的数据里搜标题与摘要
*<条目名>              直接按名字读取
```

## 自动更新

默认每天 05:00（GMT+8）跑一次增量更新（与 bookdex 同一时刻）。可在 `data/cache/config.json` 里调整：

```json
{
  "autoUpdate": { "enabled": true, "forceChannels": [] }
}
```

`forceChannels` 里填分类 key（见 `lib/srbookdex/channels.js`），填写后每天会对这些分类做强制核对。

## 暂未实现的分类

成就攻略、逐光捡金、敌对物种、装扮、家具、随宠、商店、委托、负世泰坦、黄金裔、黄金裔WIKI、活动、战利品收集、模拟宇宙。

这些分类要么信息结构复杂（攻略、图鉴表格），要么展示价值低。需要接入时把 `lib/srbookdex/channels.js` 里对应条目的 `stage` 从 `0` 改成 `1`（或 `2`）即可，抓取与渲染是同一套表驱动逻辑。
